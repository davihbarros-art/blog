# CodeLab — Blog de Tecnologia e Programação

Blog estático feito com HTML, CSS e JavaScript puro.

## Como abrir

1. Extraia a pasta `techblog`.
2. Abra o arquivo `index.html` no navegador (dois cliques).
3. Pronto. Não precisa instalar nada.

## Estrutura

```
techblog/
├── index.html      # página inicial
├── post.html       # página de artigo
├── css/style.css   # visual
└── js/main.js      # tema, menu, busca e filtros
```

## O que já vem pronto

- Layout responsivo (celular e computador)
- Tema escuro e claro
- Busca de artigos
- Filtro por categoria
- Página de post com sidebar
- Exemplos de conteúdo sobre Python, JavaScript, Web e IA

## Como personalizar

- Troque os títulos e textos nos arquivos `.html`
- Mude as cores no arquivo `css/style.css` (variáveis no `:root`)
- Adicione novos cards copiando um `<article class="post-card">`

## Publicar

Você pode enviar essa pasta para GitHub Pages, Netlify ou qualquer hospedagem de site estático.
